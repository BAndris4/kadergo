# KaderGo - Експорт Z-звітів для Excel (Chrome Extension)

Розширення для завантаження Z-звітів в один клік з кабінету платника податків [cabinet.tax.gov.ua/cashregs/zreports](https://cabinet.tax.gov.ua/cashregs/zreports) прямо у файл Excel (`.xlsx`) з точним форматуванням 1:1 за стандартом KaderGo (`excel.xlsx`).

---

## 🚀 Встановлення в браузер (Chrome / Edge / Brave)

1. Відкрийте **Google Chrome** (або Microsoft Edge / Brave / Opera).
2. Перейдіть до керування розширеннями:
   - Введіть в адресному рядку: `chrome://extensions/`
3. У правому верхньому кутку увімкніть перемикач **Режим розробника** (*Developer mode*).
4. Натисніть кнопку **Завантажити розпаковане** (*Load unpacked*) у лівому верхньому кутку.
5. Виберіть папку розширення:
   ```
   d:\Kadergo\kadergo\extensions\tax-gov-zreports
   ```
   *(або папку, експортовану з налаштувань KaderGo)*.
6. Готово! Якщо розширення вже встановлено, натисніть кнопку **Оновити** (🔄).

---

## 📋 Як користуватися

1. Перейдіть на сторінку [https://cabinet.tax.gov.ua/cashregs/zreports](https://cabinet.tax.gov.ua/cashregs/zreports).
2. Після завантаження таблиці Z-звітів над таблицею з'явиться фірмова кнопка:  
   `📥 Завантажити Excel (.xlsx) [кількість рядків]`
3. Натисніть кнопку (або відкрийте розширення на панелі браузера та натисніть «Завантажити»).
4. Браузер миттєво збереже файл (наприклад, `z_reports_жовтень_2026.xlsx`).
5. Відкрийте файл подвійним кліком — усі стовпці, висоти рядків, об'єднання комірок та підсумкові формули вже ідеально налаштовані!

---

## 📐 Параметри форматування (1:1 з excel.xlsx)

- **Ширина стовпців:**
  - 1: `Фіскальний номер документа` — 17.29 (126 px)
  - 2: `Дата і час документа` — 17.29 (126 px)
  - 3: `Фіскальний номер РРО/ПРРО` — 16.71 (122 px)
  - 4: `Реалізація - Кількість чеків` — 13.71 (101 px)
  - 5: `Реалізація - Загальна сума` — 13.29 (98 px)
  - 6: `Реалізація - Готівкова сума` — 13.86 (102 px)
  - 7: `Реалізація - Безготівкова сума` — 17.00 (124 px)
- **Висота рядків:**
  - Рядок 1 (Заголовок): строго `30.75pt` (41px).
  - Рядки даних: строго `15.0pt` (20px).
- **Підсумковий рядок:**
  - Об'єднання A:D (`оборот за [місяць рік]`), автоматичні формули підсумку (`SUM`), які Excel автоматично відображає локалізовано (`SZUM` для угорського Excel, `СУМ` для українського Excel тощо).
