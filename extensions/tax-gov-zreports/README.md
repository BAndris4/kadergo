# KaderGo - Завантажити в Excel (Chrome Extension)

Розширення для завантаження даних про оборот в один клік з кабінету платника податків [cabinet.tax.gov.ua/cashregs/zreports](https://cabinet.tax.gov.ua/cashregs/zreports) прямо у файл Excel (`.xlsx`) з точним фірмовим форматуванням 1:1 за стандартом KaderGo (`excel.xlsx`).

---

## 🚀 Встановлення в браузер (Chrome / Edge / Brave)

1. Відкрийте **Google Chrome** (або Microsoft Edge / Brave / Opera).
2. Перейдіть до керування розширеннями:
   - Введіть в адресному рядку: `chrome://extensions/`
3. У правому верхньому кутку увімкніть перемикач **Режим розробника** (*Developer mode*).
4. Натисніть кнопку **Завантажити розпаковане** (*Load unpacked*) у лівому верхньому кутку.
5. Виберіть папку розширення:
   ```
   d:\Kadergo\kadergo\extensions\tax-gov-zreports
   ```
6. Якщо розширення вже встановлено, натисніть кнопку **Оновити** (🔄).

---

## 📋 Можливості та Режими роботи

У правому кутку робочої панелі кабінету або у модальному діалозі доступні 3 основні режими експорту:

### 1. Обраний РРО (`single`)
- Завантажує Z-звіти обраного у фільтрах кабінету фіскального номера РРО.
- Автоматично розбиває будь-який діапазон дат на календарні місяці.
- Формати: **Окремі файли Excel** або **ZIP архів** з файлами кожного місяця.

### 2. Всі РРО (`all`)
- Автоматично знаходить та перебирає **всі зареєстровані фіскальні номери РРО** (`400...`).
- Для кожного календарного місяця створює зведений помісячний звіт з об'єднанням усіх РРО та підсумковими сумами.
- Формати: **Окремі файли Excel** або **Архів ZIP**.

### 3. Книга доходів — Єдиний податок (`income_book`)
- Формує офіційну **Книгу обліку доходів платника єдиного податку** за звітний рік.
- **Розумне розпізнавання:** автоматично пропонує актуальний звітний рік з наявними завершеними місяцями.
- **Гнучке налаштування періоду:**
  - Натискання на картку **«Період»** відкриває налаштування періоду.
  - Інтерактивна 12-місячна сітка (`Січ` — `Гру`) для вибору місяців в один або два кліки.
  - Поля ручного введення точних дат (`з` та `по`).
  - Кнопка **`↺ Авто`** у шапці для миттєвого скидання на стандартний авто-період.
- **Формати збереження:**
  - **Тільки Книга (.xlsx):** єдиний річний звітний файл з усіма формулами та щомісячними вкладками.
  - **Книга + щомісячні (ZIP):** Книга обліку доходів разом із детальними Z-звітами за кожен місяць в одному архіві.
- **Оптимізований друк:** налаштовано `fitToWidth="1"` / `fitToHeight="1"` без зависань при відкритті попереднього перегляду друку.

## ⚙️ Модульна Архітектура (`modules/`)

Розширення побудовано на модульній компонентній архітектурі:

| Файл | Призначення |
| :--- | :--- |
| `config.js` | Базові налаштування колонок, мапінгу чеків, готівкових та безготівкових оплат |
| `date-utils.js` | Розбір дат, розбиття періодів на місячні інтервали, генерація назв файлів |
| `cabinet-interactor.js` | Пошук селекторів кабінету, зчитування дат, вибір РРО, пагінація |
| `table-scraper.js` | Парсинг таблиці Z-звітів кабінету у структуровані масиви |
| `exporter-single.js` | Спеціалізований модуль експорту одного обраного РРО |
| `exporter-all.js` | Спеціалізований модуль пакетного збору всіх РРО |
| `exporter-book.js` | ВЕДЕТТ/ІЗОЛЬОВАНИЙ модуль річної Книги обліку доходів |
| `exporter.js` | Головний фасад та координатор процесів експорту |
| `excel.js` | Генератор щомісячних файлів Excel обороту РРО з фірмовим стилем |
| `income-book-excel.js` | Генератор офіційної Книги обліку доходів (.xlsx) з формулами та вкладками |
| `downloader.js` | Керування завантаженням файлів через Chrome Downloads API |
| `zip.js` | Клієнтська архівація множинних файлів у ZIP |
| `modal-assets.js` | Векторні SVG іконки, фірмовий логотип та анімаційні ресурси |
| `modal-dock.js` | Плаваючий міні-віджет для фонового моніторингу завантаження |
| `modal-templates.js` | DOM-шаблони та верстка уніфікованого модального вікна |
| `modal-period.js` | Компонент інтерактивного вибору періоду та сітки місяців |
| `modal-flow.js` | Контролер анімованого прогрес-бару, статусів та завершення |
| `modal.js` | Головний оркестратор модального вікна та логіки вкладок |
| `exporter.js` | Високорівневі сценарії завантаження (Single, All, Income Book) |
| `ui.js` | Інтеграція кнопок у кабінет, обробка кліків та тостів |

## 📐 Параметри форматування (1:1 з excel.xlsx)

- **Ширина стовпців:**
  - **A** (`Фіскальний номер документа`): **27.86** (200 px)
  - **B** (`Дата і час документа`): **17.86** (130 px)
  - **C** (`Фіскальний номер РРО/ПРРО`): **17.86** (130 px)
  - **D** (`Реалізація - Кількість чеків`): **15.00** (110 px)
  - **E** (`Реалізація - Загальна сума`): **15.00** (110 px)
  - **F** (`Реалізація - Готівкова сума`): **15.00** (110 px)
  - **G** (`Реалізація - Безготівкова сума`): **17.86** (130 px)
  - **H - J** (повернення, якщо є): **17.86** (130 px)
- **Висота рядків:**
  - Рядок 1 (Заголовок): `45pt`.
  - Рядки даних: `15pt`.
- **Підсумковий рядок:**
  - Об'єднання A:D (`оборот за [місяць рік]`), автоматичні формули підсумку (`SUM`).
